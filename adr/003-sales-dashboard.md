# ADR 003 · 영업 대시보드와 주변 업체

회원이 처음 대시보드를 열면 영업 지역과 업종, 키워드 최대 세 개를 입력하거나 설정을 건너뛸 수 있다. 추천은 지역과 업종이 일치하는 검색 대상 기업 중 이미 저장한 거래처를 제외하고, 검증한 키워드가 많이 일치하는 순서로 다섯 곳까지 표시한다.

추천 조건을 저장하면 DB 트리거가 지역·업종·키워드 조합을 기록한다. 운영자는 매주 SQL Editor에서 아래 쿼리로 최근 7일 동안 요청한 회원 수와 검증된 업체 수를 확인한다. 수요가 많은 조합부터 출처를 확인한 뒤 기업 키워드를 등록한다.

```sql
select * from private.weekly_keyword_demand
order by requesting_users desc, matching_companies, keyword;
```

상담 저장 시 연락 이력 추가와 다음 연락일 변경은 한 트랜잭션에서 처리한다. 다음 연락일을 비우면 후속 일정이 해제된다. 대시보드는 한국 날짜 기준으로 기한 경과, 오늘, 내일부터 이번 일요일까지의 일정을 나누고 최근 상담 다섯 건을 표시한다.

지도에서 현재 위치 버튼을 누르고 권한을 허용하면 내 위치에 파란 마커를 표시한다. 주변 업체 마커는 출처가 있는 좌표를 사용하는 기존 위치 테이블을 조회하며, 마커를 누르면 업체 상세가 열린다.
